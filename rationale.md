Why this dataset was chosen and what question it can answer
https://www.kaggle.com/datasets/isaacwen/github-programming-languages-data?resource=download

A: I chose this because I want to build a broader site about programming language information to help inform new programmers about different language popularity and best usage. Kaggle's GitHub dataset is reliable, if a bit dated, its last year was 2021

One limitation or gap in the data

A: The most recent data is from 2021, and 5 years is a long time in computer science.

Why the chosen summary metrics are meaningful rather than arbitrary

A: Pull request data is useful to see what languages are being most commonly used. This is itself useful because the more commonly used languages tend to have the most powerful libraries, the best tutorials, and sometimes, they're the most powerful languages and thus can be "swiss army knives" for a variety of programming tasks.

Why each chart type was chosen for what it displays

A: Initially the pie chart was reactive and showed the split by quarter, not by language. While this is more technically impressive, I thought it was less useful, since the point of the website is to learn about programming language differences, not quarters. So both charts show essentially the same thing, with the bar chart being reactive. Clicking in the index on a language excludes it from the pie chart. If I continue building the site I will definitely want to change that pie chart. As for why I did bar chart and pie chart, pie charts are visually pleasing, while bar charts are more accurate and not as susceptible to ocular illusions. So showing two different visualizations of the same data, one for how pleasing to the eye it is, and the other for accuracy, seemed like a good idea.
